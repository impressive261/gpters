# 유나와 동재의 커플 셀피 월드컵

휴대폰에서 사진을 선택해 바로 대결하고, 우승 사진과 전체 순위를 확인하는 모바일 웹앱입니다.

## 바로 실행

- 앱: https://impressive261.github.io/gpters/

## 주요 기능

- 모바일 갤러리에서 여러 사진을 한 번에 선택
- 2장부터 최대 200장까지 유동적으로 진행
- 99장·100장처럼 2의 거듭제곱이 아닌 수량도 예선과 부전승을 자동 배정
- 사진은 서버에 업로드하지 않고 현재 브라우저 안에서만 처리
- 대결 화면은 원본을 사용하고 목록은 경량 썸네일을 사용
- 선택 취소, 재대결, 우승 사진 공유
- 전체 결과 갤러리와 사진별 원본 전체 화면 보기·좌우 이동·공유·저장
- PWA 캐시를 통한 앱 화면 오프라인 실행 지원

## 개인정보

선택한 사진은 GitHub나 별도 서버로 전송되지 않습니다. 브라우저 탭을 새로고침하거나 닫으면 선택 상태가 초기화됩니다.
